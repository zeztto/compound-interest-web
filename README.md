# 복리 계산기

초기에 원금을 한 번 납입한 뒤, 일정한 이자율을 가정한 복리 금액과 기간별 표를 계산합니다. 원화와 달러를 각각 입력할 수 있습니다.

## 실행

Node.js 22 이상과 npm이 필요합니다. API key·계정·환경 파일·서버 설정이 필요하지 않습니다.

```sh
npm ci --ignore-scripts
npm run dev -- --host 127.0.0.1
```

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

`dist/`는 도메인 root의 HTTPS 정적 hosting에 배포할 수 있습니다. 정적 bundle을 재배포할 때 저장소의 `LICENSE`와 `THIRD_PARTY_NOTICES.md`를 함께 동봉하세요. 현재 build는 고지 문서를 자동 복사하지 않습니다. Vite dev/preview는 로컬 확인용입니다. lockfile과 CI action commit SHA를 고정했으며 CI는 Node 22·Ubuntu에서 위 검사와 build/audit를 수행하도록 구성했습니다. source 준비 단계에서 원격 CI·공개 배포 실행은 별도입니다.

## 계산 정책

- 초기 원금만 포함하며 추가 납입·출금은 없습니다. 입력 이자율은 일 365회·월 12회를 기준으로 명목 연 이자율로 단순 환산합니다.
- 연간 복리 횟수 `n`, 연 이율 `r`, 기간 `t`에 대해 `P(1+r/n)^(nt)` 모형을 사용합니다. 마지막 잔여 주기는 분수 거듭제곱으로 이자를 계산해 마지막 행에 포함합니다. 요약 최종 금액과 표 마지막 잔액은 같은 계산 값입니다.
- 원화 원금은 1원, 달러 원금은 1센트 단위입니다. 단위 버튼은 원화 원/만원/억원/조원, 달러 $/k$/m$/b$ 승수를 적용합니다. 통화 전환은 환율 환산이 아닙니다.
- 원금과 최종 금액은 원화 1조 원·달러 100억 달러까지, 기간은 최대 100년, 표는 최대 10,000개 행입니다. 입력 이자율은 선택한 기간 단위 기준 0~1,000%이며 파생 결과가 유한하지 않거나 금액 범위를 넘으면 계산하지 않습니다.
- 내부 계산은 JavaScript 부동소수점이며 화면에서 원화는 소수 0자리, 달러는 2자리로 반올림합니다. 행별 표시값의 합과 요약 표시값 사이에는 표시 반올림 차이가 있을 수 있습니다.
- 세금·수수료·금리 변동·거래일·실제 금융상품 규칙은 포함하지 않습니다. 결과는 입력 가정의 수학적 계산이며 실제 수익의 보장이 아닙니다.

입력·단위·통화를 바꾸면 이전 결과를 비웁니다. 계산 시점의 입력 snapshot으로 결과 문구를 표시하며 잘못된 입력이나 초기화 후에는 옛 결과를 남기지 않습니다. 저장소를 읽거나 쓰지 않으며 자동 저장·PWA 설치·계정·파일 내보내기 기능을 제공하지 않습니다.

## 검증

독립 반복 계산과 Python 수식 참조, 11개 Node test, 실제 table/summary·hook 상태 회귀를 실행했습니다. 13개월/6개월 복리는 3행과 `$1,066.14`, 3개월/6개월 복리는 1행과 `$1,014.89`인 USD 원금 1,000·연 6% 사례를 browser에서 확인했습니다. 0%·잘못된 값·stale/reset·한국어 copy·접근성 이름·모바일 금액 한 줄 표시를 검증했습니다. 1440×900, 768×1024, 390×844, 360×800에서 실제 화면을 확인했습니다. 추가 viewport 증거는 별도 QA 산출물로 관리합니다.

이는 선언한 계산 모형·표시·경계의 검증입니다. 실제 금융기관 계산·모든 브라우저·전체 WCAG 준수를 확인한 것은 아닙니다.
